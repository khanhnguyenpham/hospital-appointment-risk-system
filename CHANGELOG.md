# Lịch phát triển

Các ngày dưới đây phản ánh lịch sử Git thực tế của repository.

## [1.1.0] - 2026-11-18

- Thêm Expected Calibration Error vào validation, test, baseline và đánh giá theo chuyên khoa.
- Hiển thị ECE trong model card và giữ công khai việc chỉ số chưa tốt hơn baseline.
- Bổ sung test cho dự đoán hiệu chỉnh tốt, dự đoán tự tin nhưng sai và dữ liệu đầu vào không hợp lệ.

## [1.0.1] - 2026-11-18

- Bổ sung bối cảnh project trong portfolio, lịch phát triển và roadmap.
- Chuẩn hóa liên kết tới ứng dụng public và hai project liên quan.

## [1.0.0] - 2026-11-17

- Hoàn thiện pipeline dữ liệu, quality gates và chia train/validation/test theo thời gian.
- So sánh Logistic Regression với baseline và chọn threshold theo giới hạn hàng đợi review.
- Xây API online/batch, giải thích từng dự đoán và model/schema version.
- Bổ sung model card, đánh giá subgroup và monitoring PSI.
- Hoàn thiện giao diện web tiếng Việt, CI, Docker và 15 bài kiểm thử.
- Triển khai ứng dụng public trên Render.

## [0.1.0] - 2026-11-16

- Tạo workflow ban đầu cho dữ liệu tổng hợp, phân tích và mô hình.
